# 交接文档模板（agile-sprint 参考）

跨仓库任务组的执行契约。上游任务（产出方）完成后按本模板产出，下游任务（消费方）开始前必须读取。

**用途边界**：仅用于 Sprint「交接契约」段声明的跨仓库交接点；同仓库任务不产交接文档（消费 Agent 上下文自足）。

## 一、文件命名与位置

    sprints/handoffs/sprint-{序号:03d}-H{交接点序号:02d}.md

- 位置固定 `sprints/handoffs/`（随 Sprint 归档，不随某个具体仓库提交）
- 命名对应 Sprint 文件「交接契约」表中的交接点（H-001 → H01）
- 交接点序号从 01 起，跨 Sprint 不续号（每个 Sprint 独立编号）

## 二、模板

```markdown
# 交接: {交接点} {上游任务标题} → {下游任务标题}

- Sprint: sprint-{序号:03d}-{日期}
- 上游任务: {id}（repo: {仓库名}）
- 下游任务: {id}（repo: {仓库名}）
- 产出日期: {YYYY-MM-DD}

## 接口/数据契约

{上游交付给下游的接口或数据结构——按需选择并填写，未涉及的小节删除}

- 接口清单：{方法 + 路径 + 一句话用途}
- 请求/响应示例：{含字段说明与错误码}
- 数据模型：{表/对象结构、字段变更、兼容性说明}

## 配置与环境变更

- 新增/变更的配置项：{配置名 = 值，生效范围}
- 环境变量 / 依赖服务：{下游启动前需具备的前提}

## 运行与验证方式

- 上游启动步骤：{命令/顺序}
- 冒烟用例：{下游可自行验证的最小调用序列 + 期望结果}

## 未决事项与联调注意点

- {未定接口/行为歧义/后续变更预告；无则写"无"}
- {联调时的已知坑或前提假设}
```

## 三、填写规则

- **契约优先**：接口路径、字段、错误码、数据模型必须与上游真实实现一致——消费 Agent 按文档联调，写错即误导，**禁止凭规划时的设想脑补契约细节**；不确定的字段标 `{待定}` 并列入「未决事项」
- **按需裁剪**：模板小节仅保留本次交接涉及的部分，无关小节删除（如纯数据模型交接可无"配置与环境变更"）
- **完成标准**：上游任务的完成条件 = 任务本身完成 + 交接文档已产出（未产出 → DoD 关闭时归入 moved_next）；下游任务开始前必须读取对应交接文档
- **变更同步**：交接文档产出后若上游实现有变，由消费 Agent 在联调期就地更新文档（交接文档是执行期活文档，不重建闭环）
