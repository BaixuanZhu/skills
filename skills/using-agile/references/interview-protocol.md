# 产出前问询规则

需要用户拍板的决策点，用**选择题**问，不用开放式提问。

- **一次一问**：一轮只问一个，答完再问下一个，不抛长清单。
- **必给选项 + 推荐**：每个决策点给 2-4 个候选 + 明确推荐 + 一句理由 + 「自定义」兜底。
- **决策树深度优先**：先问上游最模糊的（定位），再问下游（选型 → 存储 → 缓存）。
- **文档优先**：能读项目画像 / 已有文档查到的事实自己读，不问你；只问真决策。
- **共识后落盘**：决策点问完 → 输出「决策点确认清单」（标来源）→ 你确认后才写文件。

候选选项结合实际（项目画像 / 已有文档 / 领域常识）生成，推荐给理由；不用「是/否」废话选项。追问 / 跳过规则见 `references/probing-protocol.md`。
