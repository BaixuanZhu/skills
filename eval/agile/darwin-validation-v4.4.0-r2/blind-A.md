## 问题清单

### P1
1. **`agile-backlog/SKILL.md:164` vs `:110-112` — YAML 同步时机自相矛盾**。硬约束「每次编辑 .md 后必须同步更新 .yaml」vs 阶段 3「在前两阶段确认后生成/同步，避免提前出 YAML」；阶段 1 后 agent 面临互斥指令，且 md 有/yaml 无的状态会触发 using-agile:55 双文件一致性检查。旧规则残留，应限定为「更新已有 Backlog 时」或删除。

### P2
2. **`backlog-rules.md:21,62` 门禁编号错位**：写「门禁 ⑥（拆分）」，gate-protocol §三 拆分实为 ⑤、⑥ 是 DoD 未定义；agile-backlog SKILL.md:171 自己写的是正确的「边界异常 ⑤」。
3. **`strategy-conflict-template.md:4,45` 多人团队残留**：「产品负责人」与单人+agent 设计哲学冲突。
4. **`agile-backlog/SKILL.md:90` 来源标注无落地字段**：估点/优先级标注要求在排序表 schema 无对应列。

### P3
5. 跨技能引用路径不精确（`using-agile/references/...` 靠 dependencies+搜索解析）。
6. `change-matrix.md §四` 标题「底层→上层」方向命名混乱（实义是「评估依赖方」）。
7. `probing-protocol.md:47` 维护元信息残留（「本节取代…」可删）。
8. `sprint-template.md:25` 规划期预写「执行结果: .done.yaml」。
9. `backlog-rules.md:28`「阶段 0 → 阶段 1」指代含糊，易误读为产出阶段 0-5。
10. `agile-strategic/SKILL.md:43-48`「五条规则」列了四条；agile-backlog 同样「五条」列 3 项。
11. 跨文件重复陈述：「候选 + 推荐 + 你来说」~8 处；L1/L2/L3 分级被 3 个业务技能复述。
12. `agile-backlog/SKILL.md:85 vs :123` 同文件示例 ADR 关联不一致。
13. `backlog-rules.md:50-54` 状态流转 ASCII 图箭头含糊。
14. `sprint-rules.md:10`（0.7-0.75）与 `agile-sprint/SKILL.md:44` 选项 C（0.7）口径未统一。
