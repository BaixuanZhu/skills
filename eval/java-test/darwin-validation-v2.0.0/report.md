## 三、实跑结果（`live-run.md`）

Boot 4.0.5 最小项目（18 个纯单测 + 1 个 @SpringBootTest IT）：

- **命名分离机械成立**：`mvn test` 全日志 grep failsafe/*IT 零命中；`mvn verify` 才执行 *IT。
- **轻 vs 重的时间账**：无 mock 纯单测 ≈3-5ms/条，Mockito 单测 ≈0.5s/条（含框架首启），**1 条 @SpringBootTest IT = 2.4s ≈ 800 条无 mock 单测**——"20 条分支矩阵写进容器层 ≈ 48s+ vs 纯单测 <10s"，数量锚点有直接时间账支撑。
- **Boot 4 事实抽查**：`@MockitoBean` 可注入上下文中无实现 Bean 的接口（v2 `02` 口径成立）。首跑 IT 因被测类缺 `@Service` 失败——"重型测试要求类可被容器装配"的隐性成本现场证据（纯单测无此要求）。
