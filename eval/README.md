# Eval — 达尔文评估产物

本目录存放各技能的**达尔文评估产物**（测试 prompt、隔离 agent 产出快照、判分记录、结果卡片），按技能分子目录组织。

## 目录结构

```
eval/
├── <技能名>/            # 如 java-coding-guide-pro/
│   ├── test-prompts-*.json   # 测试输入
│   ├── *_baseline.md         # 不带 skill 的对照产出
│   ├── *_with.md             # 带 skill 的产出
│   └── *.md                  # 判分记录 / 评估报告
└── README.md（本文件）
```

## 用途

- **透明可验证**：每个技能的评估输入与结果都公开，社区可自行复现或质疑。
- **跑完即提交**：评估在本仓库内进行，产物直接 commit 到对应技能子目录，不另存外部 scratch。

## 如何查看

进对应技能子目录，从评估报告 markdown（通常含「判分」「结论」章节）读起。
