# 完成的定义 (DoD)

> 本模板由 using-agile 生成，下游技能（agile-backlog / agile-sprint）读取。

## 项目画像（初始化采集，下游技能探询的公共输入）

| 项 | 值 |
|----|----|
| 项目类型 | Web 应用 |
| 团队人数与技能栈 | 4 人，Java/Vue |
| 代码基础 | 全新 |

## 任务完成标准（每个 T-/F- 条目关闭前须全部满足）
- [ ] 代码已提交并通过 CI（构建 + 单元测试）
- [ ] 功能通过验收标准（若条目展开了验收）
- [ ] 已完成代码评审（至少 1 人 approve）
- [ ] 相关文档 / API 说明已更新
- [ ] 产品负责人（PO）已验收

## Sprint 完成标准（关闭 Sprint 前须全部满足）
- [ ] 所有承诺任务满足上述「任务完成标准」
- [ ] 无遗留未解决项
- [ ] 可发布增量已在 Sprint 文件标注（若本 Sprint 含可发布增量）
