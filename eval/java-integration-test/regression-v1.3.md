3. **依赖选择不静默**：`references/04` 新增「依赖选择：探测 → 推荐 → 询问用户」节——探测表（pom 驱动 / datasource url / docker-compose）+ 推荐版本表（`postgres:17.11-alpine` / `mysql:8.4.11` / `redis:8.2.8-alpine`，MongoDB/Kafka 对齐生产）+ A/B/C 选择题询问模板（候选 + 推荐 + 理由，用户不答复时用推荐值并明示）。SKILL.md 使用流程插入第 2 步「依赖选择询问」。
4. **示例版本统一**：04/06/07 全部 `postgres:16-alpine` → `postgres:17.11-alpine`；Redis 示例 `redis:7-alpine` → `redis:8.2.8-alpine`；速查表加「推荐镜像」列。
5. **评估输入扩展**：test-prompts 新增 T11（无 H2 项目搭集成测试，定位回归核心）；T2 加「询问镜像版本」验证点；rubric 补 T11 判分锚点。
