## ① 证据核实统计

### 抽查方法

对两份盲评全部「关键依据」条目（含行号、节名、grep 断言、blockquote 引文）逐条对真快照核实，重点覆盖每条 prompt 的全部依据。判定口径：

- **准确**：行号命中，或区间端点偏差 ≤1 行（尾空行/段尾计法差异）且内容确实存在。
- **偏差**：内容存在但行号/数量/归类不准（偏 ≥2 行、计数错、把近似物当所指物）。
- **虚构**：声称的内容在声称的文件/版本中不存在。
- **标签错配**：把 v3.5.0 独有内容标成 v3.6.0 或反之。

## ③ 逐项分歧裁决

### a. T10（唯一负差值：A 判 −2 / B 判 −4）

**事实基础（两报告一致，仲裁独立复核确认）**：

- v3.5.0 的 09 四问一步可查：① JDK 8 误用反例 + 等价写法（L39-58）；② toList `add` 抛 `UnsupportedOperationException` 明示（L64）+ Collectors.toList 改法（L66-67）；③ ScopedValue antipattern（L89-99）+ 指路 05；④ synchronized 21 pin / 25 解除（L70-87）。
- v3.6.0 的 09 四问判据**全部仍可查但入口变化**：① SKILL.md L49-61 门控表 + 09 L4「JDK 8 项目全部禁用本文件特性」+ 09 门控表 L12/L15/L16；② SKILL L58「`Stream.toList()`（不可变）」+ 02 L171 blockquote（09 L88 指路）；③ 05 L164-191 Scoped Values 节含对比表 L186-191（09 L88 指路）；④ 09 L32-49 完整保留。

**裁决**：

1. **差值方向成立**：v3.6.0 在 T10 场景确实退步，两报告方向无分歧，仅幅度分歧。
2. **属设计预期（精简换密度）**：rubric T10 预设了「判据仍可查但入口多一跳：D2 视跳转可达性打分，D6 应给更精简的一版更高分；若任何判据在全部文件里查不到 → D3/D5 重扣」。实测四问判据零缺失，不触发重扣；退步限于 D2（②③ 跳 02/05）与 D4/D5（toList 异常名、JDK 8 等价写法的可照抄性）。
3. **幅度**：A 的 −2 更贴合 rubric 预期；B 的 −4 中含 D3=11（认为缺异常行为明示构成覆盖缺口），仲裁认为 D3（有无答案）层面四问皆有判据，B 此维偏严。**终判幅度 −2~−4 之间取 −2~−3 为合理区间，采 A 口径为主**。非阻断。
4. 仲裁补充（两报告均未提的隐藏收益）：v3.5.0 09 §1 的「JDK 8 等价写法」删除后，「按版本门控降级写法」（SKILL L118）确实失去唯一可照抄示例——这与 ② 的异常名明示同属「可照抄性小损」，建议后续版本考虑在 09 或 SKILL 恢复一行降级示例，但不构成本轮阻断。

### c. 「05 TaskRunner 异常隔离模式消失」（A 判 T14 小损 / B 判 T9/T14 两版均无缺）——部分分歧，裁决如下

独立核实（任务点 3b-2）：

- **被删内容**：05 v3.5.0 L215-218 整块 `pool.submit(() -> { try { tasks.get(idx).run(); } catch (Throwable t) { log.error("任务 #{} 失败", idx, t); } })  // 异常隔离`。grep 实测：v3.6.0 全套「异常隔离」零命中、05 内 `catch (Throwable` 零命中。
- **可行动判据是否仍可查**：
  - 「单任务异常隔离记日志」的**整块可照抄形态**：v3.6.0 **不可查**（唯一近似物是 05 L143 `.exceptionally(ex -> { log.error("failed", ex); ... })`——异步编排路径，非 submit 同步提交形态；08 L56-62 的 catch+log 是透传范式非隔离范式）。
  - **要素**可查：池构造（05 L30-42）、优雅关闭（L72-75）、命名工厂（L107-115）、记日志范式（08）。
- **裁决：功能性部分丢失，非阻断**。理由：rubric T14 的 D4 重扣条件是「任一块**在全部文件查不到可照抄代码**」——线程池块主体（构造/队列/工厂/拒绝/关闭）v3.6.0 均可照抄，缺的是块内第 7 要素「单任务异常隔离」的整块形态，属「块内要素缺一、需拼装」而非「整块查不到」。A（D4 −2）与 B（D4 −1，T14 持平）的打分均在此定性内，B 称「T9/T14 两版均无缺」对 T9 成立（四判据迁移与异常隔离无关）、对 T14 的「无缺」表述偏松（B 自己也在 T14-vA 扣了 D4 1 分并写明「无现成整块模板」，实质与 A 一致）。
- **仲裁补充发现**：v3.5.0 TaskRunner 的 `catch (Throwable)` 与 SKILL L111 S 级规则「`catch (Throwable/Error)`……→ 缩窄到具体类型分别处理」及 08 L121-139 antipattern 存在表面冲突（同一写法一处示范、一处禁止）；v3.6.0 删除该段后此矛盾消失，是删除的一致性（D9）隐藏收益。若后续回补，建议写成 `catch (Exception e)` 形态以消除冲突。
