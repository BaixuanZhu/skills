# java-unit-test 达尔文验证报告：v1.0.0 → v1.3.1 改进方向验证

> **目的**：用达尔文「独立盲评 + 独立仲裁 + 棘轮」原则，**证明 v1.0.0 → v1.3.1 的修改方向是正确的**（D4 可执行性↑ / D6 信息密度↑ / D3 覆盖完整↑ / D9 一致性↑），而非自评自夸。
> **日期**：2026-08-03
> **方法**：3 个独立 agent（A 盲评 / B 盲评 / 仲裁）+ 主 agent 复核修复。

## 一、评估设计

### 三层独立验证（防自评偏差）

| 层 | agent | 角色 | 独立性 |

| 1 | Agent A | 双盲打分（不知哪个是旧/新版） | 完全独立，不知 B 存在 |

| 3 | 仲裁 agent | 复核 A/B 证据真实性 + 独立查漏 | 读 A/B 报告，但独立核实 |

### 测试集（8 条 test-prompt，复用众测 T1-T8）

覆盖本次改进的 8 个改动点：JaCoCo 集成 / 遗留代码 / review checklist / 快速入门 / ArchUnit 跨层 / 停止信号 / AI 自欺 / Mock 链式。

D1 触发精度 / D2 可发现性 / D3 覆盖完整 / D4 可执行性 / D5 防错陷阱 / **D6 信息密度** / D7 内部导航 / D8 范围明确 / D9 一致性。重点严打 D4（只说要检查 X 不给命令→扣分）和 D6（说理段/重复表格/ASCII 冗余→扣分）——正是 v1.3.1 改动的两条主线。详见 `rubric.md`。

## 三、仲裁 agent 复核结论

### 证据真实性：全部 ✓

仲裁 agent 逐条核对 A/B 引用的行号，全部真实可复现（用 grep 计数 v1.0.0=0 / HEAD=N 验证新增内容）。无虚构行号或夸大改动。

### 分数尺度差异（A 比 B 高 5-15 分/prompt）

仲裁判断：**是严度差异，非误判**。B 对悬空引用/术语一致性零容忍（扣得更狠），A 聚焦主功能改进（尺度宽）。两方均无方向性误判，结论互相印证。
